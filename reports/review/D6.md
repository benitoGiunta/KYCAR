## 6. Notes de méthode (item 10, responsive/a11y)

Aucun `jsdom`/`happy-dom`/`preact-render-to-string` n'est installé dans ce dépôt (vérifié dans
`node_modules`, rien installé par cette revue). Trois composants du lot (`ModelZone.tsx`,
`SummaryBar.tsx`, `GridFooter.tsx`) n'utilisent aucun hook Preact et ont donc pu être **appelés
directement comme de simples fonctions** puis inspectés comme arbre de VNode (`role`, `tabIndex`,
`aria-*`, gestion clavier, texte) — une véritable exécution, sans DOM (`structure-a11y.test.ts`). Les
deux composants restants (`MakeCard.tsx`, `MarketScreen.tsx`) utilisent `useState`/`useMemo` : les
appeler hors du cycle de rendu Preact lève une exception, reproduite et citée en preuve
(`Cannot read properties of undefined (reading '__H')`) — pour eux, tout ce qui dépend d'un rendu réel
(bascule du champ de recherche de modèle, filtrage local, contenu conditionnel profond) est déclaré
**NON VÉRIFIABLE PAR EXÉCUTION** dans cette revue ; seule une inspection de code source (citée avec le
fichier) a été possible, ce qui a suffi à établir `R-D6-01`, `R-D6-08` et `R-D6-09` par une preuve
textuelle exacte (présence/absence de littéraux dans une tranche de code positionnellement identifiée),
mais ne prouve pas leur comportement au runtime dans un vrai navigateur.
